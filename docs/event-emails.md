# إرسال الفعاليات عبر البريد

## تجهيز Supabase

1. افتح Supabase Dashboard ثم SQL Editor.
2. انسخ محتوى `docs/event-email-dispatch.sql` وشغّله مرة واحدة.
3. من إعدادات المشروع افتح API Keys وانسخ المفتاح السري إلى `SUPABASE_SECRET_KEY` في `.env.local`. لا تستخدم بادئة `NEXT_PUBLIC_` ولا ترسل المفتاح لأحد.

## تجهيز Gmail

1. فعّل التحقق بخطوتين لحساب Gmail المرسل.
2. أنشئ App Password للبريد.
3. أضف إلى `.env.local`:

```dotenv
SUPABASE_SECRET_KEY=sb_secret_...
GMAIL_USER=your-address@gmail.com
GMAIL_APP_PASSWORD=your-16-character-app-password
```

لا تستخدم كلمة مرور Gmail الأساسية، ولا تضع هذه القيم في ملفات المشروع المشتركة أو في المتصفح. أعد تشغيل خادم Next.js بعد حفظ الإعدادات.

## الإرسال

من `/admin`، افتح إجراءات فعالية منشورة واختر **إرسال الفعالية بالبريد**. يظهر تأكيد قبل الإرسال. تصل رسالة منفصلة لكل عضو أكد بريده وفعّل تنبيهات الفعاليات من صفحة حسابه. سجل الإرسال يمنع تكرار الرسائل التي نجحت، ويمكن إعادة المحاولة عند الفشل الجزئي.

هذا الإرسال عبر Gmail مناسب لمجتمع صغير وتجربة أولية. Gmail قد يرفض اتصالات SMTP الآلية أو يقيّد الإرسال، لذلك تحقّق من حساب المرسل بعد الإرسال الأول.
